# Trump Translator

Deploy to Vercel in 2 minutes:

1. Go to https://vercel.com and sign up (free)
2. Click "Add New Project"
3. Click "Import" then choose "Upload" 
4. Upload this folder (zip it first)
5. Click Deploy
6. Your Trump Translator is live at yourproject.vercel.app

The /api/feed endpoint fetches the CNN Truth Social archive server-side,
bypassing all CORS restrictions. Feed updates every 5 minutes.
